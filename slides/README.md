# Chair slides — agentproto BOF, IETF 126

The deck is built on the **official IETF chair slide template**. The Note Well
is an official, unmodifiable slide.

## Assemble the deck

1. **Start from the official template.** Either:
   - "Make a copy" of the official Google Slides starter
     (<https://docs.google.com/presentation/d/1W930i_aYcvliMOO7eGnqlPovxhfrLSw9irbVda2E1G8/edit>),
     **or**
   - open `official/ietf-chair-slide-template.pptx`.
2. **Do not touch the Note Well slide.** Leave its text and links exactly as
   shipped. Do not add any other policy slides (IESG rule — see
   [`official/README.md`](official/README.md)).
3. **Set the front matter** on the template's title/admin slides: BOF name
   (`agentproto` — Agent Communication Protocols), IETF 126 Vienna, co-chair
   names, AD (Charles Eckel), list/Zulip, agenda links.
4. **Add the agentproto content slides** from
   [`agentproto-ietf126-content.md`](agentproto-ietf126-content.md), placed
   **after** the Note Well.
5. Export and attach to the IETF 126 session (see issue
   [#1](https://github.com/OR13/ietf-126-bof-prep/issues/1)).

## Files

- `official/` — verbatim official assets (Note Well + chair template). Do not edit.
- `agentproto-ietf126-content.md` — the agentproto-specific content slides.

## Rules

- **Note Well:** official slide only, verbatim, links preserved, nothing added.
- **No CATALIST identity:** this is the agentproto BOF deck. CATALIST is
  referenced only as prior coordination on the background slide.
- Re-download the Note Well from source before the meeting in case the IESG has
  updated it.
